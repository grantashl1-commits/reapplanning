# Welfare Incident Reporting Tool (Admin)

**Prepared by:** Dev Team
**Date:** 2026-04-09
**Status:** Draft

## Purpose
Document the admin tool for logging, tracking, and escalating participant welfare incidents.

## Requirements
- Capture incident details, participant context, and severity
- Support internal case notes and escalation paths
- Link incidents to participant records and season dates
- Provide export and reporting capabilities for board review

## Acceptance criteria
- Incident record model defined
- Escalation workflow described
- Reporting/export requirements documented
